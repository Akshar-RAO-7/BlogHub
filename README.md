📝 BlogHub (React + Vite)

BlogHub is a modern blogging platform frontend built using React ⚛️ and Vite ⚡. It enables users to create, search, and view blog posts through a clean, responsive interface.

The project focuses on component-based architecture, state management, and using the React Context API to build a scalable blogging platform UI.

📌 Project Overview

Blogging platforms require modular UI design, efficient state handling, and interactive components.
This project demonstrates how to build a React frontend that supports:

Creating blogs

Viewing blog posts

Searching/filtering posts

It is ideal for practicing modern frontend development with React and Vite.

🎯 Key Objectives

✍️ Design a responsive and intuitive blog UI

⚛️ Build reusable React components

🧠 Manage global blog state using Context API

🖊️ Implement modal-based blog creation

🔍 Add search functionality for posts

⚡ Use Vite for fast development and build performance

✨ Features

📝 Create and submit new blog posts

🔍 Search and filter posts

📄 Display blogs in a card-based layout

⚡ Fast development with Vite

🧩 Component-based scalable architecture

📱 Fully responsive UI for all screen sizes

🗑️ Empty state UI for no posts

⚙️ Installation

Clone the repository:

git clone https://github.com/Akshar-RAO-7/BlogHub.git

Navigate to the project folder:

```
cd BlogHub

```
Install dependencies:

```
npm install

```
🚀 Usage

Start the development server:

```
npm run dev

```
🔄 Development Workflow

1️⃣ Install dependencies using npm install
2️⃣ Start the development server with npm run dev
3️⃣ Edit components inside the src/ directory
4️⃣ React automatically reloads the browser during development
